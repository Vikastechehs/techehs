API v1

Introduction

The Techehs API is a REST API that returns real-time professional data as JSON. All requests are made over HTTPS to the base URL below.

https://api.techehs.com/v1

Every endpoint uses GET except the email finder, which uses POST. Responses are UTF-8 encoded JSON.

Authentication

Authenticate by sending your API key in the X-API-Key header. Find your key in the dashboard.

curl https://api.techehs.com/v1/account \
  -H "X-API-Key: YOUR_API_KEY"
Keep your key secret. Never expose it in browser code or public repositories. If a key leaks, rotate it from the dashboard immediately.

Quickstart

  1. Create a free account — you get 100 credits.
  2. Copy your API key from the dashboard.
  3. Make your first request:
curl "https://api.techehs.com/v1/company?url=https://linkedin.com/company/acme" \
  -H "X-API-Key: YOUR_API_KEY"
import { TechehsClient } from "@techehs/api";

const client = new TechehsClient({ apiKey: process.env.TECHEHS_API_KEY });
const { element } = await client.company({ url: "https://linkedin.com/company/acme" });
console.log(element.name, element.employeeCount);
from techehs import Client

client = Client(api_key="YOUR_API_KEY")
company = client.company(url="https://linkedin.com/company/acme")
print(company["element"]["name"])

Response format

Single-item endpoints return an element. List endpoints return elements plus pagination. Every response includes creditsUsed.

{
  "status": "ok",
  "element": { ... },          // single-item endpoints
  "elements": [ ... ],         // list endpoints
  "pagination": {              // list endpoints
    "page": 1,
    "pageSize": 25,
    "totalPages": 8,
    "totalElements": 193
  },
  "query": { ... },            // echo of your parameters
  "creditsUsed": 2
}

Profile

ParameterTypeDescription
urlstringProfile URL. Required if publicIdentifier is not set.
publicIdentifierstringThe profile slug, e.g. janedoe.
includeEmailbooleanAlso try to find a work email. Adds 5 credits when an email is found. Default false.

Jobs

GET /v1/jobs/search

Search live job listings. Costs 1 credit per job returned.

ParameterTypeDescription
keywordsrequiredstringSearch terms, e.g. data engineer.
locationstringCity, region or country.
companyIdstringRestrict to one company.
workplaceenumonsite, remote or hybrid.
experienceenuminternship, entry, mid, senior, director, executive.
postedWithinenum24h, week or month.
pageintegerPage number, starting at 1. Default 1.

GET /v1/job

Get full job details including the description. Parameter: id (required). Costs 1 credit.

Posts

GET /v1/posts — Recent posts from a profile or company. Costs 1 credit per post returned.

ParameterTypeDescription
profileUrlstringProfile URL. One of profileUrl or companyUrl is required.
companyUrlstringCompany page URL.
limitintegerMax posts to return, 1–100. Default 20.

People search

GET /v1/people/search — Find people by filters. Returns up to 25 results per page. Costs 5 credits per page.

ParameterTypeDescription
titlestringCurrent job title, e.g. VP Sales.
companystringCurrent company name or URL.
locationstringCity, region or country.
industrystringIndustry name.
keywordsstringFree-text keywords.
pageintegerPage number, starting at 1.

At least one filter is required.

Email finder

POST /v1/email/find — Find a verified work email. Costs 5 credits only when an email is found.

curl -X POST https://api.techehs.com/v1/email/find \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"firstName": "Jane", "lastName": "Doe", "domain": "acme.com"}'

Send either profileUrl, or firstName + lastName + domain.

{
  "status": "ok",
  "element": { "email": "jane.doe@acme.com", "verification": "valid", "confidence": 0.97 },
  "creditsUsed": 5
}

Account

GET /v1/account — Get your plan, remaining credits and concurrency limit. Free.

{
  "status": "ok",
  "element": { "plan": "growth", "creditsRemaining": 21480, "concurrency": 15, "renewsAt": "2026-11-30T00:00:00Z" },
  "creditsUsed": 0
}

Errors

Errors use standard HTTP status codes and a consistent body. Errors never cost credits.

{ "status": "error", "error": { "code": "invalid_parameter", "message": "Parameter 'url' is not a valid profile URL." } }
StatusCodeMeaning
400invalid_parameterA parameter is missing or malformed.
401unauthorizedAPI key missing or invalid.
402insufficient_creditsNot enough credits. Upgrade or top up.
404not_foundThe profile, company or job does not exist or is private.
429rate_limitedToo many concurrent requests for your plan.
500internal_errorSomething went wrong on our side. Retry with backoff.
503upstream_unavailableSource temporarily unavailable. Retry after a few seconds.

Rate limits

Limits apply to concurrent in-flight requests per account, not requests per minute.

PlanConcurrent requests
Free2
Starter5
Growth15
Business50
EnterpriseCustom

Every response includes X-Concurrency-Limit and X-Credits-Remaining headers. On 429, wait for in-flight requests to finish and retry.

SDKs

  • Node.js / TypeScript: npm install @techehs/api
  • Python: pip install techehs
  • MCP server for AI agents: npx @techehs/mcp

The SDKs handle authentication, retries with exponential backoff and typed responses.
